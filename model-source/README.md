# Current nursing-bed source

`nursing-bed.html` is the editable derivative of the user-supplied nursing-bed.html (Library libfile_93e28b3218f48191bd44fe96052131cb). The original bytes remain outside this repository in the task's attachment backup. It preserves the supplied Sketch3D geometry, kinematics, hand-ink rendering and seven-step layout, while clarifying demonstration claims and integrating reversible explosion controls.

`python3 scripts/build-model.py` copies this source to the public `care-bed.html` entry point. The other files in this folder are the historical Three.js prototype and are not used by the current build; Git history preserves the previous public design. Do not rebuild from that prototype when updating the current nursing bed.
